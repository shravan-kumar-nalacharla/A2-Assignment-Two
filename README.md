# Day 5 Assignment Projects

This repository contains the three website designs I completed for the assignment:

1. Easy Website
2. Medium Website
3. Hard website

I built these projects with HTML and CSS, using Flexbox for layout and relative/absolute positioning where needed for alignment and section placement.

## What I Used

- HTML5
- CSS3
- CSS Flexbox
- `position: relative`
- `position: absolute`
- ChatGPT for layout/reference help(minimal help for things like how to place the cards in the form of grid style)
- Nano Banana for image generation and visual support
